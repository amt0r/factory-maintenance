# Factory Maintenance

> **🚧 Work In Progress**: This project is currently in the early stages of development.

A modern Android application designed for factory workers and managers to track equipment maintenance tasks, locations, and personnel roles. It facilitates creating and monitoring tasks with varying priorities and statuses, assigning tasks to users, and attaching photos to maintenance reports.

This project heavily utilizes architecture approaches, modularization strategies, and best practices inspired by the official **[Now in Android (NiA)](https://github.com/android/nowinandroid)** sample application by Google.

## Features
- **Task Management**: Create, assign, and track maintenance tasks.
- **Prioritization**: Manage tasks using priority levels.
- **Equipment & Location Tracking**: Link tasks to specific factory equipment and physical locations.
- **User Management**: Differentiate access and responsibilities between users.
- **Modular Architecture (NiA Style)**: Built with scalable multi-module Android architecture (data, domain, ui, datastore, database, designsystem).

## Tech Stack
- **Language**: Kotlin
- **Platform**: Android
- **Build System**: Gradle (Kotlin DSL)
